# Backend-документация

В этой папке лежит документация, которая относится к backend-части проекта.

- `schema.sql` — целевая схема PostgreSQL.
- `modules/` — описание backend-модулей, endpoints и бизнес-правил.
- `guides/` — инструкции по локальному запуску, миграциям и seed-данным.
